MalDetect local development note
==============================

This file is intentionally left without live credentials.

Credentials for local testing are stored in the application database and should be managed
through the database seed scripts or by your local environment setup. Do not store plaintext
passwords, OTP secrets, or app passwords in files under the web root.

For the Gmail OTP flow, set MALDETECT_GMAIL_USERNAME and MALDETECT_GMAIL_APP_PASSWORD in
Apache/PHP environment variables or a secure local configuration file outside the public web root.

Sensitive secrets must not be committed or published online.
